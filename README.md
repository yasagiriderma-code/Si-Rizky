# Si-Rizky
Si Rizky adalah game endless runner sederhana yang terinspirasi dari gaya klasik “T-Rex runner”, namun dengan sentuhan lokal yang unik. Dalam game ini, kamu bermain sebagai Rizky, seorang bocah yang sedang berlari ketakutan karena dikejar anjing. Tugasmu sederhana: terus berlari dan bertahan selama mungkin.
